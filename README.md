## Configurar GitHub Pages

1. Ve al repositorio `Para-ali-nosotros` en GitHub.
2. Haz clic en **Settings** > **Pages**.
3. Selecciona la rama **main** y la carpeta **/ (root)**.
4. Guarda los cambios.
5. Espera 5-10 minutos.
6. Abre `https://BTSxfrijoles.github.io/Para-ali-nosotros/`.

Si sigue dando 404, revisa que `index.html` esté en la rama que elegiste y que no estés usando una carpeta `docs`.
